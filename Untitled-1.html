> Library of Halcyon (upcoming game!)

This is an upcoming project made in Scratch. This is an escape-room game where you help Hailey (the main protagonist) escape the moon and land back down to earth.

This is a placeholder room where I experiment on code and other abilities.

This is the main protagonist, Hailey! Right now she's a weird looking version of the scratch cat, but that's her unfinished design.

> WitchyWare (upcoming game for Stardance Challenge)

This is an upcoming project will be made in Godot. This is a game that takes place at the same time as Library of Halcyon. You play as Hailey's brother, Casper, attempting to escape the Immortal Witch who turned him and his sister into cats. In this game you'll need to complete the story mode (which showcases all 7 minigames) before you play endless mode.
